# Security Policy

## Reporting a vulnerability

Please report security issues privately through
[GitHub Security Advisories](https://github.com/anastanveer653/ansible-linux-server-automation/security/advisories/new)
rather than a public issue. You will get a response within a few days.

Useful details: affected role and distribution, the variables you used, and what an
attacker could do as a result (e.g. a port left open, a weaker SSH setting than documented).

## Scope

This project hardens hosts, so a default that is weaker than the README claims is treated
as a vulnerability, not just a bug.
